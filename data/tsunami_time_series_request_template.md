# Request template: time-dependent tsunami model output

Use this as a draft for the client, Daet/Gubat MDRRMO, or an appropriate technical contact. It has **not** been sent.

> We are preparing a research prototype that will replay tsunami hazard conditions together with aggregate evacuation scenarios for Gubat/Daet. We currently have static maximum-inundation depth zones, which do not provide water arrival timing or a time sequence.
>
> Could you advise whether an approved or technically reviewed, time-dependent tsunami model output is available for the Daet/Gubat coastline? We are looking for model frames or time-series data showing inundation depth (and, if available, current speed and arrival time) through the modeled event, not only a maximum-inundation map.
>
> If available, could you share or point us to:
> - the model output for one or more named scenarios and the parameters defining each scenario (including what “intensity” means);
> - time-zero definition, timestep, run duration, depth/current units, horizontal CRS, vertical datum, and grid resolution;
> - model/source version, validation basis, uncertainty/limitations, and allowed reuse/attribution terms;
> - a technical contact who can confirm how the frames and scenario results should be interpreted.
>
> If time-dependent outputs are not available for this locality, please let us know whether the static maps are maximum extents only and whether any official arrival-time estimates or approved scenario outputs can be shared for research use.

The intended application and its limitations should be explained plainly: it is a planning prototype, not a real-time warning or emergency navigation service.
