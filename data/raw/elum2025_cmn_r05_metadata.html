Description
Abstract: The Existing Land Use Map of the Province of Camarines Norte prepared under the project "ENR Data Integration for Mapping of Existing Land Uses" for CY-2025. The Project aims to map existing land uses based on high-resolution satellite imageries, produce updated data on existing land uses through the participation of LGUS and other stakeholders, and integrate existing land uses into a provincial map for monitoring land use changes and to mitigate the negative impacts of climate change. Existing Land Uses were delineated based on Google Satellite/Hybrid (2020-2024) accessed in QGIS software, other available satellite imageries, and collected maps/datasets from LGUs. The existing land use categories are in accord with the general categories indicated in the CLUP Guidebook 2013: Vol 1 (Annex 4-5. Land use Categories). Sources of information include Existing Land Use Data (LGU), Field Consultation and Validation 2025 (NAMRIA & LGU), Google Satellite/Hybrid Images (2020-2024), Land Classification Map (NAMRIA), Land Cover Map 2020 (NAMRIA), National Greening Program Map (PENRO Camarines Norte), National Integrated Protected Areas System Map (BMB) and Topographic Map 1:50,000 Scale (NAMRIA). The Administrative Boundary reflected is based on LGUs. The existing land use map was edited and finalized after the field consultation and validation with LGUs and other stakeholders. For additional information, the following were delineated separately in the map: (1) closed forest within A&D as General Production Agriculture (GPA) and (2) rice field and coconut as Crops (CRO). The Existing Land Use Map provides baseline information and integrated land uses and the current status of land resources of the province and will serve as input to the development and updating of Comprehensive Land Use Plans.
Purpose: The Existing Land Use Map (ELUM) is produced by the National Mapping and Resource Information Authority (NAMRIA) through its ENR Data Integration for Mapping of Existing Land Uses Project. It aims to map existing land uses based on high resolution satellite imageries, produce updated data on existing land uses through the participation of Local Government Units (LGUs) and other stakeholders and integrate existing land uses into a provincial map for monitoring land use changes and to mitigate the negative impacts of climate change. The Existing Land Use Map provides baseline information and integrated land uses and the current status of land resources of the province and will serve as input to the development and updating of Comprehensive Land Use Plans.

Positional Accuracy
Horizontal Positional Accuracy
Horizontal Positional Accuracy Report: The positional accuracy of the Existing Land Use Map was validated by generating Sampling Points (SP) using the stratified random sampling points in GIS Software with at least 5 SP per existing land use category. The sampling points were forwarded to the LGUs through email for final review and comments. The generated SP, the client's final review/comments and the action/s taken were documented using the Client Review of Existing Land Use Map Form (NAMRIA-ENRM-Form41 Ver3 Rev01). The accuracy of the data was computed using the consolidated client review for the province. The map accuracy of the Existing Land Use Map of Camarines Norte Province is 96.75% based on the Total Passed over the Total Number of Reviewed Categories multiplied by 100. The details of the accuracy were documented on the Accuracy Assessment of Existing Land Use Map (NAMRIA-ENRM-Form42 Ver3 Rev01).
